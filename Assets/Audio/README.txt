2048 Original SFX Pack
======================

Files:
- move.wav         Valid board movement
- merge.wav        Two tiles merging
- spawn.wav        New tile appearing
- button_click.wav UI button click
- win_2048.wav     Reaching 2048
- game_over.wav    No moves remaining

Format: 44.1 kHz, mono, 16-bit PCM WAV
These sounds were procedurally generated for this project.

Suggested Unity import settings:
- Load Type: Decompress On Load
- Compression Format: PCM or ADPCM
- Force To Mono: enabled
- Normalize: enabled
